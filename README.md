1. Install dependencies
pip install streamlit pandas numpy scikit-learn openpyxl
2. Inspect the source workbook (optional)
python inspect_attributes.py
3. Clean the dataset
Place Student Data set.xlsx in the data/ folder, then run:
python clean_data.py
This creates data/cleaned.csv. Missing predictor values are intentionally left
for the model pipeline to impute. This avoids learning imputation values from
the held-out test set.
4. Run the application
streamlit run app.py
Improvements in this version
- Modern Streamlit layout with assessment, model-performance and dataset tabs.
- Stratified train/test evaluation rather than training and reporting on the same rows.
- Reports accuracy, balanced accuracy, macro F1, per-class precision/recall/F1 and a confusion matrix.
- Trains a final prediction model on all available labelled rows after the holdout evaluation.
- Handles missing values inside the scikit-learn pipeline.
- Uses all observed school-type categories rather than silently limiting the choices to ten.
- Displays model-estimated class probabilities without calling them certainty.
- Includes clear educational safeguards and dataset limitations.
Important limitations
This remains a research prototype, not a validated student-risk assessment system.
The current interface lets a teacher enter a few fields while other predictors are
filled with typical dataset values. That can make an individual prediction less
reliable. Before any real-world use, review all predictor fields with educators,
validate the model on newer and independent schools, examine subgroup fairness,
calibrate probabilities, and establish a human review and appeal process.

The held-out metrics are a single random split, not proof of generalisation.
